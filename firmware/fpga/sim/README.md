## AI-Generated Testing and Simulation Tools

### Authorship and Attribution
All files contained within AV3D/firmware/fpga/sim were created by Claude (AI). Accordingly, authorship and credit for those files should be attributed to the AI (Opus 5.5), not to me.
These tools were devloped using AI to provide comprehensive and independent testing of the project. I have used AI intentionally to create them because I cannot independently perform fully comprehensive, non-partial testing on code I have written without potentially risking bias or overlooking critical issues.

### Purpose and Scope
The files in this directory are exclusively for testing and verification purposes. They do not contribute to the actual functionality, operation, or implementation of the project. They are independent testing utilities and do not affect any other project files, with the exception of the script responsible for intiating and coordinating the tests.
During the project showcase, these tools will be used solely to verify that the code behaves as expected and to provide additional confidence in its reliability. They are not part of the operational system and are not required for the project to function.
